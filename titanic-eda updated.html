Handling Missing Values¶

First, we checked the missing values across the dataset.
Here is how we handled them:

  • Filled missing Age with the median of the Age column.
  • Filled missing Embarked with the most frequent value (mode).
  • Dropped the Cabin column due to high missing values.
In [22]:
# Fill missing 'Age' with median
df['Age'] = df['Age'].fillna(df['Age'].median())

# Fill missing 'Embarked' with mode
df['Embarked'] = df['Embarked'].fillna(df['Embarked'].mode()[0])

# Check if 'Cabin' column exists before dropping
if 'Cabin' in df.columns:
    df = df.drop(columns=['Cabin'])

plt.show()

Feature Engineering – Family Size¶

  • A new feature FamilySize was created by summing SibSp and Parch and adding 1.
  • Smaller families (FamilySize < 3) showed better survival rates, while larger families had lower survival chances.

# Convert categorical columns to numeric
df['Sex'] = df['Sex'].map({'male': 0, 'female': 1})
df['Embarked'] = df['Embarked'].map({'S': 0, 'C': 1, 'Q': 2})

# Select only numeric columns for correlation
numeric_columns = df.select_dtypes(include=['float64', 'int64']).columns

# Correlation with target 'Survived'
corr = df[numeric_columns].corr()

# Plot the correlation heatmap
sns.heatmap(corr[['Survived']].sort_values(by='Survived', ascending=False), annot=True, cmap='coolwarm')
plt.title('Correlation with Survival')
plt.show()

Correlation with Survival¶

  • The highest positive correlations with survival were Sex (female) and Pclass (1st class).
  • Fare also shows a moderate positive correlation with survival.
  • SibSp and FamilySize are weakly negatively correlated with survival.

Conclusion¶

  • We have cleaned and explored the Titanic dataset to uncover key patterns.
  • Gender, class, and fare are the most important features influencing survival.
  • Family size can be an interesting feature for predictive modeling.
